# Django Insurance Project

## About the Project
This is a web-based insurance management system developed using Python and Django.

## Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

## Features
- Customer management
- Add and view customer details
- Insurance policy management

## Installation

1. Clone the repository.
2. Create and activate a virtual environment.
3. Install the required packages:

   pip install -r requirements.txt

4. Run migrations:

   python manage.py migrate

5. Start the server:

   python manage.py runserver
